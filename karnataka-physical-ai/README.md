# Karnataka Physical AI — State Capability Blueprint

A single-page, static digital proposal: *When AI leaves the screen, who builds the hands?*

Open `index.html` in a browser, or serve the folder (`python3 -m http.server`). No build step, no dependencies beyond Google Fonts.

- `assets/css/site.css` — visual system (obsidian / ivory / Karnataka red / precision gold)
- `assets/js/site.js` — scroll choreography, map explorer, blueprint zoom, lab configurator, roadmap
- `assets/js/karnataka-map.js` — district outlines (2011 boundaries)
- `assets/img/` — real My Equation photographs only (WebP)

Every figure carries an evidence label (Verified · Corroborated · Company-reported · Proposal · Assumption · Illustrative · To verify). Items marked **To verify** need a source attached before circulation.
